# Plixfy social profile pack

Use the same artwork on every Plixfy social account. The files only differ in resolution so the logo composition remains identical.

- `plixfy-profile-instagram-1080.png` — Instagram
- `plixfy-profile-tiktok-1080.png` — TikTok
- `plixfy-profile-facebook-1024.png` — Facebook
- `plixfy-profile-x-800.png` — X / Twitter
- `plixfy-profile-telegram-640.png` — Telegram
- `plixfy-profile-master-2048.png` — master source for future platforms

Do not crop, add text, recolor, or place another badge over the artwork.
