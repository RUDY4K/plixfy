# فكّها

نسخة Godot 4.7.1 الأولية للعبة ألغاز عربية بصرية مخصصة للجوال.

تتضمن النسخة الحالية 10 مراحل سعودية مصورة، واختيار المراحل المفتوحة، وصعوبة متدرجة، ودعم الشاشات الطويلة بدون حواف سوداء.

تبدأ الرحلة بلوحة 3×3 شبه محلولة دون تدوير، ثم تُقدّم التدوير ولوحة 4×4 تدريجيًا حتى لا يشعر اللاعب بالإحباط في أول جلسة.

## التشغيل

افتح `project.godot` في Godot واضغط تشغيل، أو نفّذ:

```powershell
godot --path games/fakkaha
```

## التحكم

- اضغط قطعة مجاورة للفراغ لتحريكها.
- اضغط أي قطعة بعيدة لتدويرها 90 درجة.
- أدوات التلميح والخلط والتراجع أسفل اللوحة.

التقدم والعملات محفوظان محليًا في `user://progress.cfg`.

## نسخة أندرويد

ملف التجربة يُنشأ في `build/fakkaha-debug.apk`. هذه نسخة موقعة بمفتاح تطوير للتجربة على أجهزة Android، أما نسخة المتجر فتحتاج مفتاح إصدار خاص قبل النشر.
