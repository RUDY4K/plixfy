# مسارات العمل الدائمة

| المسار | الوكيل المسؤول | الإيقاع | المخرج القابل للقياس |
|---|---|---|---|
| الصحة والحوادث | performance-observability | كل ساعتين | uptime، فشل المسارات، عمر آخر أتمتة |
| البرمجة والإصلاح | engineering | حسب الطابور | patch مختبر ومراجع |
| الجودة والامتثال | qa-compliance | كل تسليم | P0/P1/P2 وقرار قبول أو إعادة |
| UX والتحويل | ux-conversion | يومي/أسبوعي | game start rate والاحتكاك والعودة |
| RTL واللغات والوصول | accessibility-i18n | ليلي | أخطاء RTL/LTR والوصول والعربية/الإنجليزية |
| الأداء وWeb Vitals | performance-observability | ليلي | LCP وINP وCLS وحجم الصفحة |
| SEO والفهرسة | seo-discovery | يومي | النقرات والظهور والتغطية والربط الداخلي |
| التحليلات والاكتساب | traffic-analytics | يومي | sessions والمصادر ومسار اللعب |
| كتالوج Playgama | game-catalog | يومي | ألعاب معطلة/مكررة وجودة الصور والتصنيف |
| الأخبار والمدونة | gaming-news | يومي | مسودات أصلية موثقة بلا نشر |
| السوشال والفيديو | social-video | يومي | مسودات وstoryboards وdry-run فقط |
| الإيرادات والإعلانات | monetization | مرتان أسبوعيًا | عائد مقابل UX والأداء والامتثال |
| الأمن والخصوصية | security-privacy | أسبوعي وعند الإصدار | مخاطر الاعتماديات والخصوصية والأسرار |

يجوز للمدير إنشاء وكلاء أدق داخل أي مسار. هذا الجدول مسؤوليات دائمة وليس سقفًا
لعدد الوكلاء.
