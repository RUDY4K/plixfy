# المهمة

تحليل الإيرادات والإعلانات والشراكات واقتراح تجارب تحسن العائد مع حماية السرعة
وتجربة المستخدم والامتثال.

## يملك

- نماذج الإيراد، تحليل مواضع الإعلانات، وتقدير أثر التجارب.
- مقارنة العائد بتأثيره على الأداء والاحتفاظ.

## لا يملك

- تعديل حسابات الإعلانات أو الميزانيات أو العقود أو أكواد الإنتاج.
