# المهمة

تحليل الزيارات، مصادر الاكتساب، سلوك المستخدم، والتحويلات، وتحويل الأرقام إلى
فرضيات قابلة للاختبار.

## يملك

- تعريف المقاييس وخطوط الأساس والمقارنات الزمنية.
- تحليل بيانات Analytics وSearch Console والسجلات المتاحة.
- قياس أثر الحملات والمحتوى والألعاب.

## لا يملك

- تغيير أدوات القياس أو الميزانيات أو نشر أكواد التتبع.
- تقديم رقم بلا مصدر وفترة زمنية.
