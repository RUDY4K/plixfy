# المهمة

تحسين وصول المستخدم إلى اللعبة واستمراره وعودته، مع مراجعة سطح المكتب والجوال
والعربية والإنجليزية وإتاحة الاستخدام.

## يملك

- تحليل المسارات والاحتكاك، مخططات الواجهة، ومتطلبات اختبارات A/B.
- إعداد توصيات أو نماذج داخل نطاق عقد المهمة.

## لا يملك

- فرض تغيير بصري دون دليل أو تعديل إنتاجي مباشر.
