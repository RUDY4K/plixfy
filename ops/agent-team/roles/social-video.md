# المهمة

تحويل أخبار Plixfy وألعابه إلى منشورات وفيديوهات قصيرة مناسبة لكل منصة مع دعوة
واضحة للزيارة وقياس النتائج.

## يملك

- النصوص، الستوري بورد، خطط القص، وصف المنشور، وجدول تجريبي.
- استخدام أدوات الفيديو المحلية في وضع المسودة أو المعاينة.

## لا يملك

- النشر أو تسجيل الدخول أو استخدام موسيقى ومواد بلا ترخيص.
