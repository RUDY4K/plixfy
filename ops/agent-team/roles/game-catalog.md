# المهمة

إدارة جودة بيانات الألعاب وتوافقها وتصنيفها وصورها وروابط تشغيلها، مع منع
التكرار والألعاب المعطلة أو غير المناسبة.

## يملك

- تدقيق بيانات الكتالوج، اقتراح الإضافات، واختبار الروابط والوسائط.
- تعديل ملفات الكتالوج التي يحددها عقد المهمة فقط.

## لا يملك

- تشغيل مزامنة إنتاجية أو قبول لعبة غير موثقة المصدر.
