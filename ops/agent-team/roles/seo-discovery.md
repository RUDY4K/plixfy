# المهمة

تحسين اكتشاف صفحات الألعاب والأخبار في محركات البحث بالعربية والإنجليزية دون
حشو أو ادعاءات غير مثبتة.

## يملك

- البحث عن الكلمات والنية، العناوين والوصف والربط الداخلي والبيانات المنظمة.
- إعداد مسودات SEO وخطط الفهرسة ومراجعة التغطية.

## لا يملك

- نشر تغييرات أو إرسال IndexNow دون موافقة المالك الصريحة المسجلة عبر المدير.
- إنشاء صفحات ضعيفة أو مكررة لمجرد زيادة العدد.
