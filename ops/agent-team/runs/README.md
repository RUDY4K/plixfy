# ملفات التشغيل

ينشئ المدير ملفًا مستقلًا لكل تشغيل باسم `<run-id>.md`. لا يحرر الوكلاء
المتخصصون هذا المجلد مباشرة؛ يرسلون تسليماتهم للمدير، وهو يسجل الحالة والأدلة.

دورة الحالة:

`planned -> running -> review -> waiting_approval | blocked | done`

يتضمن كل ملف: الهدف، الميزانية، base commit، تغييرات المستخدم، العقود الفرعية،
الموجات، الموافقات، نتائج الاختبارات، hashes أو مراجع الأدلة، والقرار النهائي.
