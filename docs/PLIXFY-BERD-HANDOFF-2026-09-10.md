## 3. قرارات المالك التي يجب احترامها

هذه قرارات متكررة ومقصودة وليست اقتراحات مؤقتة:

1. لا تحدد عدد الوكلاء مسبقًا. مدير المشروع يختار العدد حسب طبيعة المهمة، ويفضل تقسيم العمل إلى وكلاء ضيقي الاختصاص عندما يحسن ذلك التركيز.
2. يوجد مدير واحد للمشروع يجمع النتائج ويقدم للمالك تقريرًا واضحًا.
3. لا تُغرق المالك بتفاصيل محادثات الوكلاء الداخلية.
4. العربية هي اللغة الأساسية للموقع، بصياغة عربية معيارية واضحة وليست لهجة مصرية. تُقبل كلمة «اونلاين» حيث تخدم البحث.
5. الرابط العربي الرسمي بلا /ar. أي /ar عام يجب أن يتحول إلى الرابط بلا بادئة. الإنجليزية فقط تحت /en.
6. تصميم الأخبار الفاتح على نمط الصحيفة كان اختيارًا مقصودًا من المالك، وليس عطلًا بصريًا يحتاج تحويله تلقائيًا إلى داكن.
7. لا تختلق تجربة لعب أو تقييمًا أو شعبية أو عدد لاعبين. فرّق بين بيانات الموزع وبين اختبار Plixfy الفعلي.
8. لا تُعد المسودة الآلية خبرًا أو دليلًا معتمدًا حتى تمر بمراجعة بشرية للمصدر والحقوق والدقة.
9. لا تعتبر عدد المنشورات نجاحًا؛ النجاح هو وصول وزيارات وتشغيل ألعاب قابل للقياس.
10. لا تعِد تفعيل Monetag لمجرد أنه موجود تاريخيًا. تم تعطيله لحماية تجربة المستخدم ومراجعة AdSense.
11. لا تستخدم النسخ المحلية القديمة لاستبدال كتالوج أحدث في الإنتاج.
12. لا تدمج كل فروع التجارب القديمة دفعة واحدة؛ افحص كل فكرة فوق أحدث main وخذ فقط ما ما زال مفيدًا.
13. أدوات ComfyUI وn8n وDocker وتجارب النماذج المحلية لم تعد جزءًا من خطة Plixfy الحالية؛ المالك قرر التركيز على Berd. لا تُعد تثبيتها أو ربطها تلقائيًا.

## 6. البنية التقنية الحالية

### الواجهة والتشغيل

- Next.js 16.2.12 باستخدام App Router.
- React وReact DOM 19.2.4.
- TypeScript.
- Tailwind CSS 4.
- Sharp لمعالجة الصور.
- Lucide React للأيقونات.
- Vercel للنشر.
- Vercel Analytics.
- Supabase للهوية والملفات الشخصية والمفضلة وسجل اللعب.

قبل أي تعديل يعتمد على API خاص بـNext 16، راجع وثائق النسخة المثبتة داخل node_modules/next/dist/docs لأن سلوك الإصدارات القديمة قد لا ينطبق.

### التوجيه واللغات

- الصفحات الفعلية داخل src/app/[locale].
- العربية داخليًا /ar لكنها خارجيًا بلا بادئة.
- /ar و/ar/* يتحولان 301 إلى الرابط العربي بلا بادئة على الإنتاج.
- الإنجليزية /en و/en/*.
- proxy يحمي dashboard بالمصادقة الأساسية.
- إذا غابت بيانات دخول dashboard يرجع 404 بدل كشف وجوده.
- slugs الأخبار العربية القديمة تتحول إلى slugs إنجليزية نظيفة.

### المسارات الرئيسية

- الرئيسية: / و/en
- كل الألعاب: /all-games و/en/all-games
- التصنيفات: /categories و/category/[slug]
- صفحة اللعبة: /play/[slug]
- التشغيل التدريجي: /play/[slug]/launch
- البحث: /search
- المفضلة: /favorites
- الحساب والملف: /auth و/profile
- لوحة خاصة: /dashboard
- دليل ألعاب المتصفح: /guides/browser-games

- المدونة: /blog

- مختبر الألعاب الأصلية: /lab
- RSS للأخبار والمدونة.
- sitemap وrobots.

### الحسابات والبيانات

- Supabase SSR/client.
- تسجيل/استعادة كلمة المرور ومسار callback.
- مفضلة للضيف محليًا ومزامنة عند توفر الحساب.
