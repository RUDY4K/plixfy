## 2. تسجيل المقاطع (15 دقيقة للخمسة)

1. افتح اللعبة على الموقع في كروم (وضع ملء الشاشة F11)
2. **Win+G** → سجّل — العب 40-60 ثانية وتعمّد لقطة مثيرة (موتة قريبة، فوز، موقف مضحك)
3. افتح **CapCut** (مجاني):
   - قصّ لأفضل 12-15 ثانية — **أقوى لقطة في أول ثانية** (الـhook البصري)
   - حوّل لعمودي 9:16: اللعبة بالنص، وفوق/تحت خلفية blur من نفس المقطع
   - أضف نص الـHook كبيراً أول ثانيتين
   - موسيقى تريند من مكتبة CapCut التجارية (المرخصة للإعلانات)
   - آخر ثانيتين: «plixfy.com — بدون تحميل» بخط كبير
4. صدّر 1080×1920

> ⚠️ لا تستخدم مقاطع جيم بلاي من يوتيوب/تيك توك لغيرك في الإعلانات المدفوعة —
> ترفض بالمراجعة وتكرارها يبند الحساب الإعلاني.

> ads.tiktok.com — سجّل بحساب البزنس (plixfy.com@gmail.com)، العملة SAR، ادفع مسبق (prepay) للتحكم بالصرف

| هدف الحملة | **Traffic** (زيارات موقع) |
| ميزانية الحملة | لا تفعّل CBO — حدد على مستوى المجموعة |
| المجموعات الإعلانية | 3 مجموعات × **10 ريال/يوم** = 30 ريال/يوم (~300 بالشهر مع أيام إيقاف) |
| المجموعة أ | إعلانا موتو + دراجات (سباق) |
| المجموعة ب | إعلانا البرينروت + السيوف (ترند/أكشن) |
| المجموعة ج | السلة + الأسهم (تحدي/رياضة) |
| الاستهداف | السعودية فقط، 13-34 سنة، الجنس: الكل |
| الاهتمامات | Gaming → Mobile Games + Casual Games (لا تضيّق أكثر — خلّ الخوارزمية تتعلم) |
| المواضع | TikTok فقط (أطفئ Pangle وGlobal App Bundle) |
| التحسين | Landing page view (مو Click) |

**قاعدة الأسبوع الأول:** لا تلمس شي 4 أيام (فترة التعلم). بعدها: أوقف أي إعلان CPC حقه فوق 1 ريال، وضاعف ميزانية الأفضل.
